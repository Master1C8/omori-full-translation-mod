# OMORI — переводчик игры с локальным кэшем

Независимый мод-переводчик для Steam-версии **OMORI** на Windows и macOS. Игра и её текстовые/исполняемые ресурсы в проект не входят и не изменяются; оригинальная иконка используется только для узнаваемости совместимого приложения.

Мод поддерживает два явных способа заполнения кэша. `Bulk Translate All Assets` заранее извлекает поддерживаемые строки из `.HERO`, а `Screen Translation` вообще не читает ассеты: кнопка `Translate current screen` собирает только текст активных видимых окон OMORI и переводит его в этот момент. В Screen можно отдельно включить автоматический перевод завершившихся страниц диалога; эта опция выключена по умолчанию и не отправляет меню. Story и Full автоматически применяют только готовый кэш.

## Возможности экспериментальной версии 0.9.44

- **Оригинальная иконка OMORI**: приложение и оба релизных архива используют тот же pixel-art `icon/icon.png`, который указан в `package.json` установленной игры. Для macOS он упакован в ICNS, для Windows — в многослойный ICO.
- **Три изолированных режима перевода**: `Story Translation` сохраняет стабильный cache-only перевод диалогов, имён и вариантов ответа; `Full Translation` дополнительно применяет готовый кэш к меню; `Screen Translation` переводит по кнопке только текст, видимый прямо сейчас, включая уже подставленные значения строк-шаблонов. Возврат в Story немедленно перерисовывает системные окна оригиналом; последний стабильный снимок остаётся под Git-тегом `v0.9.43-stable`.
- **Полный охват естественных реплик**: апострофы, `this.`, дроби, даты, `/`, `+` и `*` внутри английского диалога больше не принимаются за программный код. Технические пути и идентификаторы по-прежнему отсекаются общим анализатором исходного текста.
- **Надёжная запись кэша**: RAM и счётчики обновляются только после подтверждённого commit IndexedDB; ошибка записи или полной очистки показывается пользователю вместо ложного успеха.
- **Проверка слабых моделей**: технические строки, engine keys, подписи этажей и Base64 не отправляются провайдеру, ALL CAPS нормализуется локально, а усечённые, повторяющиеся, оставившие существенный английский текст или потерявшие числа/валюту ответы не записываются в кэш.
- **Проверяемая цепочка сборки macOS**: архив NW.js 0.115.0 закреплён SHA-256, а релизный тест автоматически запускает браузерный runtime smoke.
- **Упрощённый список сервисов**: встроенные офлайн-провайдеры удалены из интерфейса, helper и сценариев сборки. Установленная macOS `.app` обновлена; релизные ZIP нужно пересобрать отдельно. Ранее скачанные данные удалённых провайдеров не затрагиваются обычным обновлением.
- **Честный ETA текущего прохода**: интерфейс по-прежнему показывает обработанные слова, но скорость времени до завершения измеряется только по новым переводам, созданным после нажатия кнопки. Мгновенные cache hit больше не выдают себя за быстрые запросы; найденный кэш лишь уменьшает оставшийся объём.
- **Однократное извлечение ассетов**: после первого Bulk каталог поддерживаемых строк из `.HERO` сохраняется в отдельный локальный индекс. В него входят диалоги и многие подписи меню. Следующие Bulk сразу используют его; изменение каталога, имени, размера или времени модификации исходного файла автоматически запускает пересчёт. Повреждённый индекс безопасно перестраивается.
- **Строгая защита разметки OMORI**: единый лексический слой для всех моделей отделяет служебные команды, экранированные кавычки, HTML-подобные теги и квадратные метаданные до обращения к провайдеру. Модель получает только обычные текстовые сегменты. Для связанных частей сначала делается одна контекстная попытка с нейтральными разделителями; повреждение разделителя включает безопасный посегментный fallback. Мод локально собирает результат с неизменным исходным skeleton и проверяет его перед записью в кэш.
- **OpenAI-compatible AI**: готовые профили OpenCode Go, OpenRouter, DeepSeek и LM Studio, а также произвольный совместимый Base URL и выбор модели через `/models`.
- **Сохраняемый журнал перевода**: панель показывает новые пары `English → Translation`, а локальный helper сохраняет их между запусками; последние 200 записей можно посмотреть в приложении, полный журнал — сохранить в JSONL-файл.
- **Полноэкранный режим перевода**: во время Bulk или Test Phrase всё окно занимает живой журнал; видны счётчик обработанных слов с расчётным временем/обратным отсчётом ограничения, фиксатор `Stop scroll` и кнопка `Interrupt translation (progress will be saved)`. Stop приостанавливает только автопрокрутку, не перевод. После успешного завершения обычная панель восстанавливается автоматически; после остановки или неполного прохода журнал и причина остаются на экране до нажатия `Back to translator`.
- **Защита от Steam-ярлыков на macOS**: сохранённый путь проверяется на наличие настоящих ресурсов NW.js; ярлык `OMORI.app`, созданный Steam на рабочем столе, автоматически отбрасывается в пользу установленной игры.
- **Нативный запуск на Apple Silicon**: переводчик получает разрешение на запуск от работающего Steam и открывает OMORI через совместимый ARM64-движок вместо аварийного Intel Chromium. В этом режиме локальные сохранения и перевод работают, но достижения, Steam Cloud и Steam Overlay недоступны.
- **Массовый перевод всех ассетов**: кнопка `Bulk Translate All Assets` расшифровывает игровые текстовые файлы (`.HERO`) рядом с фактически выбранной копией игры и создаёт кэш через выбранный сервис.
- **Надёжное сворачивание панели**: кнопка `−` больше не перехватывается обработчиком перетаскивания; короткое нажатие свёрнутого `+` раскрывает панель непосредственно на `pointerup`, а движение по-прежнему переносит кнопку.
- **Мгновенный офлайн-геймплей**: после массового перевода готовые записи хранятся в постоянном кэше и подставляются без сети и задержек. Строки, которых нет в кэше, остаются английскими.
- **Умное кэширование**: групповые запросы автоматически разбиваются на индивидуальные записи для мгновенного подхвата диалоговыми и, в режиме Full, системными окнами.
- **Надёжная фоновая обработка**: Массовый перевод продолжается при сворачивании OMORI или переключении в другое приложение; при ручной остановке, смене настроек, сетевой ошибке или лимите сервиса панель показывает конкретную причину и сохраняет готовые записи.
- **Исправленное позиционирование текста**: Перевод диалогов больше не «съезжает» благодаря корректному сбросу состояния окна сообщения при обновлении текста.
- автоматическое применение готового кэша к новым репликам, именам говорящих и вариантам ответа в Story;
- экономное автоматическое применение готового перевода только к видимым и изменённым блокам Story/Full с полной паузой, когда окно игры скрыто;
- canvas-текст диалоговых окон и, в Full, поддерживаемых системных окон OMORI подхватывается из постоянного кэша по мере фактической отрисовки;
- ручное применение в `Screen Translation` через кнопку или `Ctrl+Shift+T` и отдельная отключаемая опция автоматического перевода завершившихся страниц диалога;
- мгновенное переключение `Original / Translation`;
- каталог из 249 целевых кодов для сетевых и AI-провайдеров;
- выбор между Google Translate, Gemini AI, LM Studio Local AI и OpenAI-compatible AI;
- контекстный перевод Gemini 2.5 Flash-Lite с личным API-ключом в системном защищённом хранилище;
- постоянный дисковый кэш отдельно по языкам и переводчикам с ограниченным RAM-слоем на 50 000 последних записей;
- самовосстанавливающаяся статистика постоянного кэша;
- повтор только неудачных запросов;
- сохранение позиции панели;
- предупреждение о непроверенной версии OMORI;
- интерфейс мода всегда остаётся на английском независимо от выбранного языка;
- корректное направление и выравнивание игрового текста для языков с написанием справа налево;
- языковая разметка, шрифтовые цепочки для разных письменностей и правила переноса для CJK и сложных письменностей;
- безопасное разбиение по цельным символам, включая диакритику, индийские слоги, флаги и составные emoji;
- контекстный перевод оформленных фраз с сохранением исходных HTML-элементов;
- в `Story Translation` системный интерфейс остаётся оригинальным; `Full Translation` применяет готовый кэш, а `Screen Translation` переводит только текущие видимые `Window_Base`-окна по кнопке. Надписи-изображения и отдельные sprite-bitmap без окна могут остаться английскими;

## Запуск

Перед запуском переводчика закройте OMORI, если она уже открыта.

- **Windows:** полностью распакуйте Windows ZIP и откройте `OMORI Translator.exe`. Лаунчер сначала использует сохранённый путь, затем ищет Steam-библиотеку и AppID `1150690`. Если поиск не удался, он попросит выбрать игровой `.exe`. Права администратора не нужны.
- **macOS:** откройте `OMORI Translator.app`. Универсальное приложение работает на Apple Silicon и Intel Mac с macOS 12 или новее и запускает игру. Если стандартный путь отсутствует, приложение попросит указать исполняемый файл внутри установленной игры.

На Apple Silicon Steam должен быть открыт. OMORI может кратко появиться и автоматически перезапуститься в совместимом ARM64-режиме. В этом режиме работают игра, локальные сохранения и перевод, но не достижения, Steam Cloud и Steam Overlay.

Если macOS просит выбрать игру вручную, указывайте настоящую `OMORI.app` из Steam-библиотеки, содержащую `Contents/Resources/app.nw`. Не выбирайте маленький ярлык `OMORI.app` на рабочем столе: внутри него находится только команда открытия Steam. Начиная с 0.9.18 лаунчер распознаёт такой ярлык, игнорирует ошибочно сохранённый путь и восстанавливает реальный путь автоматически.

При первом запуске выберите сервис, язык и способ работы. Для заранее подготовленного перевода нажмите `Bulk Translate All Assets`. Для перевода без чтения ассетов выберите `Screen Translation` и нажимайте `Translate current screen` на нужном экране. Удалённый сервис получает текст при запуске выбранной операции; LM Studio на loopback-адресе обрабатывает его на этом компьютере. Переключение `Original` отключает применение перевода.

По умолчанию выбран стабильный `Story Translation`. Появление незнакомой строки в Story или Full не запускает скрытый запрос. `Full Translation` использует заранее созданный кэш для меню и других `Window_Base`-окон. В `Screen Translation` кнопка одобряет точные видимые canvas/DOM-строки текущих окон; отдельная выключенная по умолчанию опция может вместо этого автоматически одобрять только завершившуюся страницу диалога. Выбранный режим и опция сохраняются.

Интерфейс самого мода всегда отображается на английском. Выбор в поле `Language` меняет язык диалогов, имён и вариантов ответа; в `Full Translation` он также применяется к поддерживаемым системным окнам OMORI. Кнопки, настройки и сообщения панели переводчика остаются английскими.

Простая инструкция на английском и русском: [`docs/USER_GUIDE.md`](docs/USER_GUIDE.md).
Сводка текущих изменений: [`docs/CHANGELOG.md`](docs/CHANGELOG.md).

## Управление

- toggle `Translation / Original` переключает уже обработанный текст;
- `Translate current screen (Ctrl+Shift+T)` в режиме `Screen Translation` переводит только видимый сейчас текст; повторное нажатие кнопки или той же комбинации во время работы отменяет текущий экранный проход;
- `Automatically translate completed dialogue` в Screen автоматически запускает тот же защищённый cache/provider-путь после завершения печати текущей страницы реплики; меню остаются ручными;
- в развёрнутой панели всегда видны язык, переводчик, настройки выбранного локального или сетевого сервиса и статистика кэша; язык, переводчик, endpoint и выбранная модель сохраняются сразу после изменения;
- единственная кнопка `− / +` в заголовке переключает всю панель и один плюсик;
- развёрнутую панель можно переносить за заголовок, а свёрнутую — перетаскиванием самого плюсика.

Ссылка VN Revival открывает сайт проекта во внешнем системном браузере. Рядом находятся кликабельные иконки Discord, Telegram и электронной почты.

## Кэш

В настройках отображаются число переводов и полезный объём данных. Статистика хранится отдельно и не заставляет приложение перечитывать весь кэш при каждом открытии настроек. Перед изменением IndexedDB устанавливается маркер незавершённой операции; RAM и статистика меняются только после успешного commit. После аварийного закрытия мод увидит dirty-маркер и восстановит статистику потоковым обходом. Дополнительно число записей сверяется при следующем запуске.

В оперативной памяти остаются только 50 000 последних переводов; полный кэш хранится в IndexedDB без искусственного ограничения. В панели показываются число записей выбранного языка, их полезный объём и общая статистика. `Export cache backup` сохраняет резервную копию. `Load translation file` сначала полностью проверяет чужой JSONL/JSON-кэш, определяет игру, язык, провайдера/вариант и число записей, а затем показывает отдельное окно подтверждения. Выбранный перевод хранится обратимым слоем поверх собственного provider-кэша и удаляется кнопкой `Remove imported`, не затрагивая локально созданные переводы.

Версия 0.9.29 вводит вторую схему защищённой разметки и при первом запуске очищает старые записи переводов, которые могли содержать повреждённые команды, кавычки или пробелы рядом с `\aub`, `\!`, `<br>` и `[TRASH]`. Это не удаляет сохранения OMORI, API-ключи и файл истории переводов. Новые и импортированные записи применяются только при совпадении токенов и структурного положения управляющей разметки с английским оригиналом.

Синяя кнопка массового перевода расположена над импортом и экспортом. Сразу после нажатия она показывает вращающийся индикатор. На время Bulk или Test Phrase панель переходит в полноэкранную рабочую область: остаются строка прогресса, живой журнал, фиксатор `Stop scroll` и закреплённая кнопка `Interrupt translation (progress will be saved)` с тем же цветом и spinner, что у запустившей операцию кнопки; заголовок, сворачивание и остальные настройки временно скрыты. Успешное завершение автоматически возвращает обычную панель. Остановка или неполный результат оставляют рабочую область и итоговую причину открытыми, а нижняя кнопка меняется на `Back to translator`. Пока нет как минимум двух свежих переводов и двух секунд активного замера, время показано как `calculating…`; cache hit, подготовка провайдера и cooldown в ETA не входят.

`Reset all data` выполняет полный сброс переводчика до состояния новой загрузки: удаляет provider-кэш и RAM-кэш, импортированные паки, сохранённую историю и логи, оставшиеся файлы прежних провайдеров, API-ключи, настройки, запомненный путь игры и служебные метаданные. Сама OMORI и её сохранения не затрагиваются; при следующем запуске путь будет снова найден автоматически либо выбран пользователем. После подтверждения кнопка показывает `Resetting…`, блокирует повторное нажатие и по завершении просит перезапустить переводчик.

При каждом запуске мод через локальный helper проверяет `https://vnrevival.fun/downloads/omori/latest.json`. Под заголовком постоянно виден результат: `Checking for updates…`, актуальная версия, доступная версия с пометкой `translation cache will be kept`/`translation cache rebuild required` либо `Could not check for updates`. Если обновление найдено, ниже показываются до трёх кратких изменений из поля `changes`; пока источник описаний не настроен, используется явная заглушка. Ошибка сети, тайм-аут, HTTP-ошибка и некорректный манифест не мешают запуску игры и всегда отображаются явно. Эта функция пока только проверяет наличие релиза и ничего не скачивает и не устанавливает.

Раздел `Live translation log` автоматически раскрывается при обработке результата Bulk и Test Phrase и показывает исходную английскую строку, стрелку и готовый перевод вместе с временем, языком и провайдером. Каждый новый проход очищает только живую область, поэтому записи прежнего языка, провайдера или модели не смешиваются с текущими. Кэш-попадания отмечаются словом `cache`, поэтому журнал движется с первой строки даже при продолжении готовой операции. Во время перевода журнал занимает всё свободное место полноэкранной рабочей области. `Stop scroll` фиксирует текущую видимую строку: список можно листать вручную, а новые записи продолжают добавляться сверху; `Resume scroll` возвращает к новым строкам и обычному автоследованию. Чтобы интерфейс не замедлялся при многочасовом переводе, живой список хранит 40 новейших пар; во время Stop дополнительно удерживается ограниченное окно до 40 строк вокруг текущей позиции. Локальный helper отдельно дополняет `translation-history.jsonl` уникальными парами provider/language/source/translation: `View saved` загружает в панель последние 200 записей, а `Save file` сохраняет полный журнал. Повторный проход не раздувает файл дублями. `Clear view` очищает только панель и не удаляет сохранённую историю; полный `Reset all data` удаляет и её. Обычное воспроизведение уже готовых реплик в игре журналом не засоряется.

Кнопка `Test Phrase · All Languages` продолжает работать при переключении в другое приложение и обрабатывает языки последовательно. Бесплатный Google endpoint принимает только один целевой язык за запрос, поэтому Test Phrase делает запрос раз в секунду и полный проход без ограничений обычно занимает около 5 минут. При `HTTP 429` Test Phrase и обычный Bulk полностью прекращают Google-запросы на 15 минут, показывают обратный отсчёт, сохраняют срок и следующую ступень паузы между запусками, затем повторяют тот же запрос вместо записи `failed`. Повторные ограничения увеличивают паузу до 30 и 60 минут даже после перезапуска приложения. Кнопка прерывания остаётся доступной, а готовые строки уже сохранены в кэше и будут пропущены при следующем запуске.


Большой перевод одного языка и этот тест нагружают сервис по-разному. `Bulk Translate All Assets` сначала быстро обходит готовые записи кэша, затем объединяет только отсутствующие Google-переводы в защищённые блоки максимум по 12 строк и 3200 UTF-8 байт. Блоки отправляются последовательно с интервалом не менее 5 секунд, а каждый полученный перевод проверяется и сохраняется под индивидуальным ключом исходной строки. Общая quality-проверка блока отключена: независимо проверяются все 12 результатов. Если отдельная строка отклонена, корректные результаты того же ответа сразу сохраняются и повторяется только отклонённый остаток; бинарное деление применяется лишь когда из целого ответа нельзя принять ни одной строки. После полного отклонения размер следующих блоков уменьшается вдвое вплоть до 3 строк, после частичного — на 2; четыре чистых блока подряд увеличивают его на 2 обратно до 12. Неудачная одиночная или двухстрочная длинная запись не уменьшает следующие блоки, а пятсекундный интервал действует при любом размере. Вытянутые вокализации и повторяющиеся стилизованные дефисные названия не считаются обычным английским carryover. Только конкретные строки, которые не проходят даже отдельно, становятся `failed`. Если три исходных полных блока подряд не дают ни одного пригодного результата, Bulk останавливается как при системной проблеме, сохраняя уже готовый кэш. При ограничении строка состояния явно показывает `Rate limited by Google Translate · retrying in …` и не увеличивает ни `done`, ни `failed`, пока текущий запрос не будет успешно повторён. Test Phrase использует тот же сохранённый cooldown, но сохраняет собственный интервал в одну секунду. Перезапуск приложения не обходит ограничение. Для немедленного продолжения можно выбрать другой сервис, но он создаст собственные записи кэша.

Новые ключи кэша содержат идентификатор игры, поэтому переводы разных игр не смешиваются. Для LM Studio и OpenAI-compatible AI ключ также включает endpoint, выбранную модель и версию переводческой инструкции: смена сервиса или модели не подменяет новые результаты старым кэшем.

## Сетевые сервисы и приватность

Google используется через публичный endpoint без API-ключа. Это неофициальная для массового использования точка доступа: она может изменить правила или ограничить частоту запросов. Каталог мода содержит 249 кодов Google.

При массовом переводе через удалённый сервис нажатие `Bulk Translate All Assets` сразу запускает обработку: выбранному провайдеру отправляются извлечённые строки `.HERO`, а не только текущий экран. Во время обычного игрового процесса Story и Full работают с локальным кэшем и ничего не отправляют провайдеру; свежие запросы Screen запускаются только кнопкой/горячей клавишей либо включённой пользователем автоматической опцией.

## Gemini AI

Выберите `Gemini AI`, получите собственный ключ на [Google AI Studio](https://aistudio.google.com/apikey), вставьте его в поле `Gemini API key` и нажмите `Save API key`. Мод использует `gemini-2.5-flash-lite` и просит сохранять имена, тон и взрослый смысл исходника. Служебная разметка модели не отправляется.

Ключ не записывается в настройки игры или кэш переводов. После отправки поле очищается, а ключ хранится отдельно для игры:

- **macOS:** в macOS Keychain;
- **Windows:** в Windows Credential Manager, включая отдельное хранилище бутылки CrossOver при таком запуске.

Кнопка `Remove key` удаляет ключ из системного хранилища. Бесплатная квота и скорость зависят от аккаунта и могут изменяться; при `429` мод показывает сообщение о достигнутом лимите и позволяет повторить неудачные блоки позже. На бесплатном тарифе Google может использовать отправленный текст для улучшения своих продуктов. Регулируемые фильтры для взрослого текста отключены, но встроенные ограничения Gemini сохраняются, поэтому отдельные сцены могут быть заблокированы. Актуальные условия: [pricing](https://ai.google.dev/gemini-api/docs/pricing), [rate limits](https://ai.google.dev/gemini-api/docs/rate-limits), [safety settings](https://ai.google.dev/gemini-api/docs/safety-settings).









## LM Studio Local AI

Выберите `LM Studio Local AI`, запустите локальный сервер в разделе Developer приложения LM Studio и нажмите `Refresh models`. Стандартный адрес — `http://127.0.0.1:1234`. Затем выберите модель из списка и запустите `Bulk Translate All Assets`.

Мод обращается к OpenAI-совместимым маршрутам `/v1/models` и `/v1/chat/completions` через собственный защищённый helper. Текст не покидает компьютер, CORS для LM Studio включать не требуется. Для стабильного результата используются температура `0`, структурированный JSON-ответ и проверки RPG Maker-кодов и маркеров контекста. Если модель не поддерживает JSON Schema, helper повторяет запрос в обычном текстовом режиме.

LM Studio и модель должны оставаться доступными до завершения массового перевода. Мод не запускает и не останавливает LM Studio автоматически. Локальные модели обрабатываются последовательно, чтобы несколько генераций не конкурировали за одну и ту же RAM/VRAM.

## OpenAI-compatible AI

Выберите `OpenAI-compatible AI`, затем профиль `OpenCode Go`, `OpenRouter`, `DeepSeek`, `LM Studio` или `Custom`. Для удалённого профиля вставьте API-ключ и нажмите `Save API key`; для локального LM Studio ключ не нужен. Нажмите `Refresh models`, выберите модель из полученного списка либо введите её точный ID вручную.

Для регистрации в OpenCode Go можно использовать [нашу реферальную ссылку](https://opencode.ai/go?ref=SS6M8DKPP0): новому пользователю начисляется $5 на баланс. Та же ссылка показывается непосредственно в настройках профиля OpenCode Go и открывается в системном браузере.

Встроенные Base URL: `https://opencode.ai/zen/go/v1`, `https://openrouter.ai/api/v1`, `https://api.deepseek.com` и `http://127.0.0.1:1234/v1`. Произвольный удалённый адрес обязан использовать HTTPS; HTTP разрешён только для loopback. Ключ хранится отдельно для каждого Base URL в macOS Keychain или Windows Credential Manager и никогда не передаётся в JavaScript игры или кэш переводов.

Эта интеграция использует OpenAI Chat Completions: `GET /models` и `POST /chat/completions`. Поэтому у OpenCode Go подходят модели, доступные через Chat Completions; модели, работающие только через Responses API или Anthropic Messages API, пока не поддерживаются. Структурированный JSON автоматически откатывается к обычному текстовому ответу, если выбранная модель не поддерживает JSON Schema.

## Шрифты и письменности

Переведённый блок сначала сохраняет исходный шрифт игры, затем получает цепочку подходящих системных шрифтов и Noto для своей письменности. Это улучшает Arabic, Hebrew, NKo, Indic, Thai, CJK и другие языки, но сами Noto-шрифты не входят в мод: полный комплект для сотен письменностей был бы слишком тяжёлым. Если на компьютере нет шрифта с нужными символами, его необходимо установить отдельно.

## Подпись публичного релиза

Обычная локальная сборка остаётся ad-hoc подписанной на macOS и неподписанной на Windows. Сборочные сценарии готовы использовать настоящий сертификат:

- `VNREVIVAL_MAC_SIGN_IDENTITY` — Apple Developer ID Application; `VNREVIVAL_MAC_NOTARY_PROFILE` — профиль `notarytool` для нотариального заверения;
- `VNREVIVAL_WINDOWS_SIGN_CERT` и `VNREVIVAL_WINDOWS_SIGN_PASSWORD` — PFX-сертификат Authenticode; при необходимости задаются `VNREVIVAL_WINDOWS_SIGN_TOOL` и сервер временных меток.

Без купленных и выданных Apple/Microsoft-совместимых сертификатов предупреждения Gatekeeper и SmartScreen полностью убрать нельзя.

## Сборка и проверка

После первого клонирования подготовьте закреплённую среду разработки:

```bash
mise install
uv sync
```

`mise.toml` фиксирует Node.js 22.23.2, Python 3.14.6 и полный Xcode. `uv sync`
создаёт `.venv` с Pillow и `pip`; Windows-сборщик автоматически использует
один и тот же `.venv/bin/python` для подготовки зависимостей и иконки. При
необходимости нестандартный интерпретатор по-прежнему можно задать через
`VNREVIVAL_HOST_PYTHON` и `VNREVIVAL_ICON_PYTHON`.

```bash
./scripts/test-runtime.sh   # browser/runtime unit checks, concise output
./scripts/test-service.sh   # local helper/provider checks, concise output
./scripts/test-omori.sh
./scripts/build-omori.sh
```

В `launcher/READY_TO_SHARE/` всегда остаются ровно два актуальных файла: ZIP для macOS и ZIP для Windows. Промежуточное `.app`, контрольные суммы и предыдущие версии хранятся вне папки готовой раздачи или удаляются сборщиком.

Каждая публичная команда привязана к одной игре: она не может случайно собрать другой мод. Общие сценарии требуют явную внутреннюю цель: `VNREVIVAL_GAME=<game-id> ./scripts/build.sh`. Полный контракт и порядок добавления игры описаны в [`docs/ADAPTER_CONTRACT.md`](docs/ADAPTER_CONTRACT.md).

В текущем контракте исходный язык игры фиксирован как английский. Имя основного `.exe` остаётся обязательным в манифесте для автоматического поиска и контроля процесса, но пользователь всегда может выбрать фактический файл вручную.
