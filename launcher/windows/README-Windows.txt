__PRODUCT_NAME__ for Windows — VN Revival
https://vnrevival.fun/

1. Fully extract this ZIP to a regular folder.
2. Double-click __PRODUCT_NAME__.exe.
3. The workbench opens in your default browser and keeps all project data local.

The application has one purpose: extract game text through an adapter, create
OpenAI-compatible draft translations, import editor-approved final text, and
build a static localization package. AI drafts cannot be built as a release.

API keys are stored in Windows Credential Manager. Project files never contain
credentials. Do not move the EXE by itself: the resources folder must remain
beside it. Administrator rights are not required and source game files are not
modified.

Workbench data:
%LOCALAPPDATA%\VN Revival\Localization Workbench
